# 🏠 House Price Prediction

A Machine Learning project that predicts house prices based on various property-related features.

## 📌 Project Overview

House Price Prediction is a Machine Learning project developed to estimate the price of a house using historical housing data.

The project includes data preprocessing, exploratory data analysis, feature engineering, model training, and evaluation.

## 🎯 Objectives

- Analyze housing dataset
- Clean and preprocess the data
- Identify important features affecting house prices
- Train Machine Learning models
- Evaluate model performance
- Predict house prices for new input data

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
